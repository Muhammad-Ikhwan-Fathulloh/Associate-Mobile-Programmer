Konsep

Apa Itu API

  • API adalah kontrak: alamat (/notes), metode (GET, POST), dan format data (JSON).
  • Aplikasi mengirim permintaan, server mengirim jawaban dengan kode status.
  • Tampilan tidak perlu tahu detail jaringan. Tugas itu ada di lapisan klien API.

Praktik

Server Latihan

  • Jalankan npm start di shared/server, lalu server ada di localhost:3000.
  • Akun latihan: peserta@contoh.id dengan kata sandi rahasia123.
  • Emulator Android memanggil komputer lewat 10.0.2.2. Ponsel fisik memakai IP komputer.

Klien API di lib/services

Tampilan hanya memanggil metode seperti login atau daftarCatatan.

api_client.dart (ringkasan)

class ApiClient {
  ApiClient(this.baseUrl, {http.Client? client})
      : _client = client ?? http.Client();

  Future<String> login(String email, String password) async {
    final r = await _kirim('POST', '/login',
        body: {'email': email, 'password': password});
    return (r as Map)['token'] as String;
  }

  Future<List<dynamic>> daftarCatatan(String token) async =>
      (await _kirim('GET', '/notes', token: token)) as List<dynamic>;
}

Berkas: lib/services/api_client.dart · Materi: bagian 5

Konsep

Menangani Kegagalan

  • ApiException membawa kode status dan pesan dari server. Tampilkan pesannya.
  • Status 204 tidak punya isi. Jangan memanggil jsonDecode pada badan kosong.
  • Pasang batas waktu di setiap permintaan agar aplikasi tidak menunggu tanpa akhir.
  • HTTP ke alamat publik ditolak. HTTP hanya untuk alamat lokal saat pengembangan.

Cek Koneksi Sekali

LANGKAH 2lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan aplikasi.
  3. Tekan tombol Periksa.
import 'package:connectivity_plus/connectivity_plus.dart';
import 'package:flutter/material.dart';

String label(List<ConnectivityResult> hasil) {
  if (hasil.isEmpty || hasil.contains(ConnectivityResult.none)) {
    return 'Tidak ada koneksi';
  }
  if (hasil.contains(ConnectivityResult.wifi)) return 'Wi-Fi';
  if (hasil.contains(ConnectivityResult.mobile)) return 'Seluler';
  return 'Lainnya';
}

void main() => runApp(const MaterialApp(home: JaringanPage()));

class JaringanPage extends StatefulWidget {
  const JaringanPage({super.key});

  @override
  State<JaringanPage> createState() => _JaringanPageState();
}

class _JaringanPageState extends State<JaringanPage> {
  String _teks = 'Tekan Periksa';

  Future<void> _periksa() async {
    final hasil = await Connectivity().checkConnectivity();
    setState(() => _teks = label(hasil));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Jaringan')),
      body: Center(
        child: Text(_teks, style: Theme.of(context).textTheme.headlineMedium),
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _periksa,
        label: const Text('Periksa'),
      ),
    );
  }
}
Hasil yang benar Teks menampilkan Wi-Fi, Seluler, atau Tidak ada koneksi sesuai kondisi saat ditekan.

Praktik Modul 5 · Langkah 3 dari 3

Pantau Perubahan (Stream)

LANGKAH 3lib/main.dart (ganti kelas _JaringanPageState)
  1. Tambahkan import 'dart:async'; di baris paling atas.
  2. Ganti _JaringanPageState dengan kode di bawah.
  3. Matikan lalu nyalakan Wi-Fi atau mode pesawat, amati teks.
class _JaringanPageState extends State<JaringanPage> {
  List<ConnectivityResult> _hasil = [];
  StreamSubscription<List<ConnectivityResult>>? _langganan;

  @override
  void initState() {
    super.initState();
    Connectivity().checkConnectivity().then((h) {
      if (mounted) setState(() => _hasil = h);
    });
    _langganan = Connectivity().onConnectivityChanged.listen((h) {
      setState(() => _hasil = h);
    });
  }

  @override
  void dispose() {
    _langganan?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Jaringan')),
      body: Center(
        child: Text(
          label(_hasil),
          style: Theme.of(context).textTheme.headlineMedium,
        ),
      ),
    );
  }
}
Hasil yang benar Teks berubah sendiri tanpa tombol. dispose membatalkan langganan agar tidak bocor.

Praktik Modul 5 · Coba Sendiri

Coba Sendiri

Kerjakan tanpa melihat jawaban. Tanyakan bila macet lebih dari 5 menit.

  1. Tampilkan kartu peringatan bila koneksi seluler: unduhan besar sebaiknya menunggu Wi-Fi.
  2. Tampilkan kartu informasi bila tidak ada koneksi: data tersimpan tetap dapat dibuka.
  3. Tambahkan label Ethernet dan VPN pada fungsi label.

Praktik Modul 5 · Cek Hasil

Kriteria Selesai

  • Label berubah saat Wi-Fi dimatikan
  • Langganan stream dibatalkan di dispose
  • Kondisi offline ditangani dengan pesan ramah
  • Peserta tahu bahwa 2G sampai 5G tidak dapat dibaca lewat paket ini
