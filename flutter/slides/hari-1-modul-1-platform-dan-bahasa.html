Instalasi

Pasang Flutter SDK

  1. Unduh SDK dari docs.flutter.dev/get-started/install.
  2. Ekstrak ke folder tanpa spasi, misalnya C:\src\flutter.
  3. Tambahkan folder flutter\bin ke PATH, lalu buka ulang terminal.
# macOS dan Linux
mkdir -p ~/development
tar -xf ~/Downloads/flutter_linux_*.tar.xz -C ~/development
echo 'export PATH="$HOME/development/flutter/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

Dart

Dart Essentials

void main() {
  String nama = 'Peserta';
  final kota = 'Bandung';   // nilai tidak berubah setelah diberikan
  const pi = 3.14159;       // nilai konstan saat kompilasi

  String? catatan;          // boleh null (null safety)
  print(catatan ?? 'Tidak ada catatan');

  ambilData().then((hasil) => print(hasil));
}

Future<String> ambilData() async {
  await Future.delayed(const Duration(seconds: 1));
  return 'Data berhasil diambil';
}

Tata cara membuat

  1. Buat file bin/main.dart atau buka DartPad (dartpad.dev).
  2. Tulis void main() sebagai titik masuk.
  3. Deklarasikan variabel dengan final atau const.
  4. Pakai async dan await untuk pekerjaan yang butuh waktu.
  5. Jalankan, lalu ubah nilai dan amati hasilnya.

Widget

Widget dan Widget Tree

Segala sesuatu di layar adalah widget. Widget tersusun dalam pohon.

StatelessWidget

class HaloFlutter extends StatelessWidget {
  const HaloFlutter({super.key});

  @override
  Widget build(BuildContext context) {
    return const Text('Halo Flutter!');
  }
}

StatefulWidget

class CounterWidget extends StatefulWidget {
  const CounterWidget({super.key});

  @override
  State<CounterWidget> createState() =>
      _CounterWidgetState();
}

Tata cara membuat

  1. Mulai dari satu widget akar, misalnya Scaffold.
  2. Isi appBar dengan AppBar(title: Text(...)).
  3. Isi body dengan Center(child: Text(...)).
  4. Pilih StatelessWidget bila tampilan tetap, StatefulWidget bila berubah.

Siklus hidup

Siklus Hidup State

MethodKeterangan
initState()Dipanggil sekali saat widget dibuat. Cocok untuk inisialisasi controller.
didChangeDependencies()Dipanggil setelah initState dan saat dependensi berubah.
build()Membangun tampilan. Sebaiknya tanpa efek samping.
dispose()Dipanggil saat widget dihapus. Lepaskan controller dan stream di sini.

Tata cara membuat

  1. Buat StatefulWidget dengan class State.
  2. Isi initState() untuk inisialisasi, misalnya controller.
  3. Tulis tampilan di build() tanpa efek samping.
  4. Lepaskan controller dan stream di dispose().

Dart Dasar

LANGKAH 2dasar.dart (di folder latihan)
  1. Buat file dasar.dart di folder latihan.
  2. Salin kode, simpan.
  3. Jalankan dart run dasar.dart.
class Mahasiswa {
  Mahasiswa(this.nama, this.nilai);
  final String nama;
  final int nilai;

  String get predikat => nilai >= 80 ? 'A' : nilai >= 70 ? 'B' : 'C';
}

int jumlah(List<int> data) {
  var total = 0;
  for (final x in data) {
    total += x;
  }
  return total;
}

void main() {
  const sapaan = 'Halo';
  String? panggilan; // boleh bernilai null
  print('$sapaan ${panggilan ?? 'Peserta'}');

  print('Total: ${jumlah([90, 75, 60])}');

  final data = {'Ani': 90, 'Budi': 75};
  data.forEach((nama, n) => print('$nama: ${Mahasiswa(nama, n).predikat}'));
}
Hasil yang benar Keluaran: Halo Peserta, Total: 225, Ani: A, Budi: B.

Praktik Modul 1 · Langkah 3 dari 4

Counter Sendiri

LANGKAH 3lib/main.dart
  1. Buka lib/main.dart, hapus seluruh isinya.
  2. Tempel kode di bawah, simpan.
  3. Jalankan flutter run atau tekan r bila sudah berjalan.
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      theme: ThemeData(colorSchemeSeed: Colors.indigo, useMaterial3: true),
      home: const HalamanCounter(),
    );
  }
}

class HalamanCounter extends StatefulWidget {
  const HalamanCounter({super.key});

  @override
  State<HalamanCounter> createState() => _HalamanCounterState();
}

class _HalamanCounterState extends State<HalamanCounter> {
  int _nilai = 0;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Counter Latihan')),
      body: Center(
        child: Text('$_nilai', style: Theme.of(context).textTheme.displayLarge),
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: () => setState(() => _nilai++),
        child: const Icon(Icons.add),
      ),
    );
  }
}
Hasil yang benar Angka bertambah setiap tombol + ditekan. setState membangun ulang tampilan.

Praktik Modul 1 · Langkah 4 dari 4

Hot Reload dan Hot Restart

LANGKAH 4lib/main.dart
  1. Ubah Colors.indigo menjadi Colors.teal dan simpan.
  2. Tekan r di terminal: warna berubah, angka tetap.
  3. Tekan R (hot restart): angka kembali ke 0.
theme: ThemeData(colorSchemeSeed: Colors.teal, useMaterial3: true),
Hasil yang benar Hot reload mempertahankan state. Hot restart mengulang dari awal.

Praktik Modul 1 · Coba Sendiri

Coba Sendiri

Kerjakan tanpa melihat jawaban. Tanyakan bila macet lebih dari 5 menit.

  1. Tambahkan tombol reset (Icons.refresh) yang mengembalikan angka ke 0.
  2. Tampilkan teks Genap atau Ganjil di bawah angka (petunjuk: _nilai.isEven).
  3. Ubah penambahan menjadi kelipatan 5.
