Layanan Lokasi dengan geolocator

Future<bool> pastikanIzin() async {
  if (!await Geolocator.isLocationServiceEnabled()) return false;

  var izin = await Geolocator.checkPermission();
  if (izin == LocationPermission.denied) {
    izin = await Geolocator.requestPermission();
  }
  return izin == LocationPermission.whileInUse ||
      izin == LocationPermission.always;
}

Stream<Position> pantauPosisi({int jarakMinimalMeter = 5}) {

      distanceFilter: jarakMinimalMeter,
    ),
  );
}

  4. Tangkap LocationException dan tampilkan pesan.

Jarak

Menghitung Jarak (Haversine)

double jarakMeter(double lat1, double lon1, double lat2, double lon2) {
  final dLat = _keRadian(lat2 - lat1);
  final dLon = _keRadian(lon2 - lon1);

  final sinLat = sin(dLat / 2);
  final sinLon = sin(dLon / 2);

  final a = sinLat * sinLat +
      cos(_keRadian(lat1)) * cos(_keRadian(lat2)) * sinLon * sinLon;

  return 2 * _jariJariBumiMeter * asin(sqrt(a));
}
  • Hasil dalam meter. Package geolocator juga menyediakan Geolocator.distanceBetween.

Tata cara membuat

  1. Ubah derajat ke radian.
  2. Hitung selisih lintang dan bujur.
  3. Terapkan rumus Haversine dengan jari-jari bumi 6.371.000 m.
  4. Tulis fungsi jarakMeter(lat1, lon1, lat2, lon2) dan uji dengan flutter test.

LANGKAH 2haversine.dart (di folder latihan_lokasi)

  2. Salin kode, simpan.

import 'dart:math';

double _rad(double d) => d * pi / 180;

double jarakMeter(double lat1, double lon1, double lat2, double lon2) {
  const r = 6371000.0;
  final dLat = _rad(lat2 - lat1);
  final dLon = _rad(lon2 - lon1);
  final a = pow(sin(dLat / 2), 2) +
      cos(_rad(lat1)) * cos(_rad(lat2)) * pow(sin(dLon / 2), 2);
  return 2 * r * asin(sqrt(a));
}

void main() {
  // Monas (Jakarta) ke Gedung Sate (Bandung), koordinat perkiraan
  final m = jarakMeter(-6.1754, 106.8272, -6.9025, 107.6186);
  print('${(m / 1000).toStringAsFixed(1)} km');
}
Hasil yang benar Keluaran sekitar 119.1 km.

Praktik Modul 4 · Langkah 3 dari 4

Ambil Posisi Pengguna

LANGKAH 3lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan di emulator atau ponsel.
  3. Tekan tombol dan setujui dialog izin.
import 'package:flutter/material.dart';
import 'package:geolocator/geolocator.dart';

void main() => runApp(const MaterialApp(home: LokasiPage()));

class LokasiPage extends StatefulWidget {
  const LokasiPage({super.key});

  @override
  State<LokasiPage> createState() => _LokasiPageState();
}

class _LokasiPageState extends State<LokasiPage> {
  String _teks = 'Belum ada posisi';

  Future<void> _ambil() async {
    if (!await Geolocator.isLocationServiceEnabled()) {
      setState(() => _teks = 'GPS tidak aktif');
      return;
    }
    var izin = await Geolocator.checkPermission();
    if (izin == LocationPermission.denied) {
      izin = await Geolocator.requestPermission();
    }
    if (izin == LocationPermission.denied ||
        izin == LocationPermission.deniedForever) {
      setState(() => _teks = 'Izin lokasi ditolak');
      return;
    }
    final p = await Geolocator.getCurrentPosition();
    setState(() => _teks = '${p.latitude}, ${p.longitude}');
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Lokasi')),
      body: Center(child: Text(_teks, textAlign: TextAlign.center)),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _ambil,
        icon: const Icon(Icons.my_location),
        label: const Text('Ambil lokasi'),
      ),
    );
  }
}
Hasil yang benar Koordinat tampil. Di emulator, atur lokasi lewat Extended controls, menu Location.
