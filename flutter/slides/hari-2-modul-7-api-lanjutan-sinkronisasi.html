Konsep

Alur Offline-First

  1. Catatan disimpan lokal dengan status PENDING.
  2. Saat Sinkronkan ditekan, setiap catatan PENDING dikirim.
  3. Catatan baru memakai POST. Catatan yang punya serverId memakai PUT.
  4. Yang berhasil menjadi SYNCED dan menyimpan serverId.
  5. Aplikasi mengambil daftar dari server dan menyimpan yang belum dikenal.

Kode

Sinkronisasi di sync_service.dart

Satu kegagalan tidak menghentikan catatan lain.

sync_service.dart (ringkasan)

for (final Note n in await repo.catatanPending()) {
  try {
    final hasil = n.serverId == null
        ? await api.buatCatatan(token, badan)
        : await api.ubahCatatan(token, n.serverId!, badan);
    await repo.tandaiSynced(n.id!, hasil['id'] as int);
    terkirim++;
  } catch (_) {
    gagal++; // satu kegagalan tidak menghentikan yang lain
  }
}

Konsep

Token dan Penyimpanan Aman

  • Token jangan disimpan di SQLite atau SharedPreferences, karena tidak terenkripsi.
  • Gunakan flutter_secure_storage: Keystore di Android, Keychain di iOS.
  • Hapus token saat pengguna keluar.

Konsep

Mendeteksi Jenis Koneksi dan Ancaman

  • connectivity_plus memberi tahu saat koneksi berubah: Wi-Fi, seluler, atau tidak ada.
  • Komunikasi nirkabel bisa disadap. Kirim semua data lewat HTTPS.
  • periksaUrlApi menolak HTTP ke alamat publik sebelum permintaan dikirim.

Validasi URL (Tanpa Perangkat)

LANGKAH 1url_check.dart (di folder latihan_aman)
  1. Buat file url_check.dart.
  2. Salin kode, simpan.
  3. Jalankan dart run url_check.dart.
/// Mengembalikan pesan error jika URL tidak aman, atau null jika aman.
String? periksaUrlAman(String url) {
  final uri = Uri.tryParse(url.trim());
  if (uri == null || !uri.hasAuthority) {
    return 'URL tidak valid.';
  }
  if (uri.scheme != 'https') {
    return 'Gunakan HTTPS (https://).';
  }
  return null;
}

void main() {
  for (final u in ['https://contoh.test/a', 'http://contoh.test/a', 'bukan url']) {
    print('$u -> ${periksaUrlAman(u) ?? 'aman'}');
  }
}
Hasil yang benar https diterima (aman), http ditolak dengan pesan HTTPS, teks bebas dianggap tidak valid.

Praktik Modul 7 · Langkah 2 dari 3

Simpan Token di Secure Storage

LANGKAH 2lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan di emulator atau ponsel.
  3. Isi token, tekan Simpan, lalu tutup dan buka aplikasi.
import 'package:flutter/material.dart';
import 'package:flutter_secure_storage/flutter_secure_storage.dart';

void main() => runApp(const MaterialApp(home: TokenPage()));

class TokenPage extends StatefulWidget {
  const TokenPage({super.key});

  @override
  State<TokenPage> createState() => _TokenPageState();
}

class _TokenPageState extends State<TokenPage> {
  static const _storage = FlutterSecureStorage();
  final _input = TextEditingController();
  String _tersimpan = '(belum ada)';

  @override
  void initState() {
    super.initState();
    _muat();
  }

  @override
  void dispose() {
    _input.dispose();
    super.dispose();
  }

  String _samarkan(String t) =>
      t.length <= 4 ? '****' : '${t.substring(0, 2)}****${t.substring(t.length - 2)}';

  Future<void> _muat() async {
    final t = await _storage.read(key: 'token');
    if (!mounted) return;
    setState(() => _tersimpan = t == null ? '(belum ada)' : _samarkan(t));
  }

  Future<void> _simpan() async {
    await _storage.write(key: 'token', value: _input.text.trim());
    _input.clear();
    await _muat();
  }

  Future<void> _hapus() async {
    await _storage.delete(key: 'token');
    await _muat();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Token Aman')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Column(
          children: [
            TextField(
              controller: _input,
              obscureText: true,
              decoration: const InputDecoration(
                labelText: 'Token',
                border: OutlineInputBorder(),
              ),
            ),
            const SizedBox(height: 12),
            Row(
              children: [
                FilledButton(onPressed: _simpan, child: const Text('Simpan')),
                const SizedBox(width: 12),
                OutlinedButton(onPressed: _hapus, child: const Text('Hapus')),
              ],
            ),
            const SizedBox(height: 24),
            Text('Tersimpan: $_tersimpan'),
          ],
        ),
      ),
    );
  }
}
Hasil yang benar Token tampil tersamar (misalnya ab****yz) dan tetap ada setelah aplikasi dibuka ulang.

Praktik Modul 7 · Langkah 3 dari 3

Panggil API Lewat HTTPS

LANGKAH 3lib/api.dart (halaman baru)
  1. Buat lib/api.dart, tempel kode.
  2. Ubah home di main.dart menjadi const ApiPage() dan tambahkan import 'api.dart';.
  3. Jalankan, tekan Ambil data. Matikan internet untuk melihat pesan galat.
import 'dart:convert';

import 'package:flutter/material.dart';
import 'package:http/http.dart' as http;

class ApiPage extends StatefulWidget {
  const ApiPage({super.key});

  @override
  State<ApiPage> createState() => _ApiPageState();
}

class _ApiPageState extends State<ApiPage> {
  String _hasil = 'Tekan Ambil data';

  Future<void> _ambil() async {
    setState(() => _hasil = 'Memuat...');
    try {
      final res = await http
          .get(Uri.parse('https://jsonplaceholder.typicode.com/posts/1'))
          .timeout(const Duration(seconds: 10));
      if (res.statusCode != 200) {
        throw Exception('Status ${res.statusCode}');
      }
      final data = jsonDecode(res.body) as Map<String, dynamic>;
      setState(() => _hasil = '${data['title']}');
    } catch (e) {
      setState(() => _hasil = 'Gagal: $e');
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('API HTTPS')),
      body: Center(child: Padding(padding: const EdgeInsets.all(16), child: Text(_hasil))),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _ambil,
        label: const Text('Ambil data'),
      ),
    );
  }
}
Hasil yang benar Judul post dari JSONPlaceholder tampil. Tanpa internet muncul pesan Gagal, bukan aplikasi menggantung.

Coba Sendiri

Kerjakan tanpa melihat jawaban. Tanyakan bila macet lebih dari 5 menit.

  1. Panggil periksaUrlAman sebelum http.get dan tolak URL non-HTTPS.

  3. Tampilkan pesan khusus bila terjadi TimeoutException.

Latihan

Latihan Modul 7

  1. Matikan server, buat dua catatan, lalu sinkronkan. Pastikan keduanya tetap PENDING.

  3. Ubah catatan yang sudah SYNCED, lalu sinkronkan. Pastikan server menerima PUT.
