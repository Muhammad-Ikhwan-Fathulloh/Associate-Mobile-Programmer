Kode

Membaca Accelerometer

import 'package:sensors_plus/sensors_plus.dart';

final langganan = accelerometerEventStream().listen((event) {
  // event.x, event.y, event.z dalam m/s2
});

// Wajib dibatalkan saat layar ditutup
langganan.cancel();

Tata cara membuat

  1. Panggil accelerometerEventStream().listen(...) di initState.
  2. Simpan event terakhir di State dan panggil setState.
  3. Hitung besar percepatan dengan sqrt(x² + y² + z²).
  4. Wajib cancel() langganan di dispose().

Praktik Modul 6 · Langkah 1 dari 3

Baca Akselerometer

LANGKAH 1lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan di ponsel, atau emulator (Extended controls, Virtual sensors).
  3. Gerakkan perangkat dan amati x, y, z.
import 'dart:async';

import 'package:flutter/material.dart';
import 'package:sensors_plus/sensors_plus.dart';

void main() => runApp(const MaterialApp(home: SensorPage()));

class SensorPage extends StatefulWidget {
  const SensorPage({super.key});

  @override
  State<SensorPage> createState() => _SensorPageState();
}

class _SensorPageState extends State<SensorPage> {
  AccelerometerEvent? _e;
  StreamSubscription<AccelerometerEvent>? _sub;

  @override
  void initState() {
    super.initState();
    _sub = accelerometerEventStream().listen((e) {
      setState(() => _e = e);
    });
  }

  @override
  void dispose() {
    _sub?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final e = _e;
    return Scaffold(
      appBar: AppBar(title: const Text('Akselerometer')),
      body: Center(
        child: Text(
          e == null
              ? 'Menunggu data'
              : 'x: ${e.x.toStringAsFixed(2)}\n'
                  'y: ${e.y.toStringAsFixed(2)}\n'
                  'z: ${e.z.toStringAsFixed(2)}',
          style: Theme.of(context).textTheme.headlineMedium,
        ),
      ),
    );
  }
}
Hasil yang benar Saat diam di meja, z mendekati 9,8 (gravitasi). Nilai berubah saat digerakkan.

Praktik Modul 6 · Langkah 2 dari 3

Deteksi Guncangan

LANGKAH 2lib/main.dart (ubah listener dan tampilan)
  1. Tambahkan import 'dart:math'; dan variabel int _goyang = 0;.
  2. Ganti isi listen dengan kode di bawah.
  3. Tampilkan $_goyang pada Text.
    _sub = accelerometerEventStream().listen((e) {
      final total = sqrt(e.x * e.x + e.y * e.y + e.z * e.z);
      setState(() {
        _e = e;
        if (total > 15) _goyang++;
      });
    });
Hasil yang benar Guncangan keras menaikkan penghitung. Ambang 15 m/s² di atas gravitasi (9,8).

Praktik Modul 6 · Langkah 3 dari 3

Info Perangkat

LANGKAH 3lib/info.dart (halaman baru)
  1. Buat lib/info.dart, tempel kode.
  2. Di main.dart ubah home menjadi const InfoPage() dan tambahkan import 'info.dart';.
  3. Jalankan di perangkat Android.
import 'package:device_info_plus/device_info_plus.dart';
import 'package:flutter/material.dart';

class InfoPage extends StatelessWidget {
  const InfoPage({super.key});

  Future<String> _ambil() async {
    final info = await DeviceInfoPlugin().androidInfo;
    return '${info.brand} ${info.model}\n'
        'Android ${info.version.release} (API ${info.version.sdkInt})';
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Info Perangkat')),
      body: Center(
        child: FutureBuilder<String>(
          future: _ambil(),
          builder: (context, snap) {
            if (!snap.hasData) return const CircularProgressIndicator();
            return Text(snap.data!, textAlign: TextAlign.center);
          },
        ),
      ),
    );
  }
}
Hasil yang benar Merek, model, dan versi Android perangkat tampil. Kode ini khusus Android.

Praktik Modul 6 · Coba Sendiri

Coba Sendiri

Kerjakan tanpa melihat jawaban. Tanyakan bila macet lebih dari 5 menit.

  1. Tambahkan debounce agar satu guncangan hanya dihitung sekali (simpan waktu terakhir dan beri jeda 500 ms).
  2. Tampilkan bar indikator LinearProgressIndicator sesuai besar percepatan.
  3. Tambahkan Platform.isIOS agar halaman info tidak gagal di iOS.
