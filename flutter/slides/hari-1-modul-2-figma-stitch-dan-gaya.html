Konsep

Google Stitch

  • Alat dari Google Labs: teks atau gambar menjadi rancangan antarmuka.
  • Perbaiki rancangan dengan chat, lalu ekspor ke Figma sebagai layer yang bisa diedit.
  • Hasil Stitch adalah titik awal. Rapikan struktur dan token sebelum menjadi kode.
  • Fitur dan menu Stitch cepat berubah. Cek tampilan terbaru sebelum sesi.
Tunjukkan Stitch secara langsung bila ada akses. Tulis prompt yang menyebut layar, isi, dan gaya, lalu perbaiki lewat chat.

Praktik Modul 2 · Langkah 1 dari 3

Tema, Daftar, dan Navigasi

LANGKAH 1lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan aplikasi.
  3. Ketuk salah satu menu untuk membuka halaman detail.
import 'package:flutter/material.dart';

void main() => runApp(const MyApp());

class MyApp extends StatelessWidget {
  const MyApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Latihan UI',
      theme: ThemeData(colorSchemeSeed: Colors.teal, useMaterial3: true),
      home: const DaftarPage(),
    );
  }
}

class DaftarPage extends StatelessWidget {
  const DaftarPage({super.key});

  static const _menu = ['Catatan', 'Lokasi', 'Jaringan', 'Sensor'];

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Beranda')),
      body: ListView.builder(
        padding: const EdgeInsets.all(16),
        itemCount: _menu.length,
        itemBuilder: (context, i) => Card(
          child: ListTile(
            leading: const Icon(Icons.apps),
            title: Text(_menu[i]),
            trailing: const Icon(Icons.chevron_right),
            onTap: () => Navigator.of(context).push(
              MaterialPageRoute(builder: (_) => DetailPage(judul: _menu[i])),
            ),
          ),
        ),
      ),
    );
  }
}

class DetailPage extends StatelessWidget {
  const DetailPage({super.key, required this.judul});
  final String judul;

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text(judul)),
      body: Center(child: Text('Halaman $judul')),
    );
  }
}
Hasil yang benar Daftar empat menu. Mengetuk menu membuka halaman, tombol kembali berfungsi.

Praktik Modul 2 · Langkah 2 dari 3

Form dengan Validasi

LANGKAH 2lib/main.dart (tambahkan kelas di bagian bawah)
  1. Tempel kelas FormPage di akhir file.
  2. Ubah home: const DaftarPage() menjadi home: const FormPage().
  3. Coba simpan dengan judul kosong, lalu dengan judul valid.
class FormPage extends StatefulWidget {
  const FormPage({super.key});

  @override
  State<FormPage> createState() => _FormPageState();
}

class _FormPageState extends State<FormPage> {
  final _kunci = GlobalKey<FormState>();
  final _judul = TextEditingController();

  @override
  void dispose() {
    _judul.dispose();
    super.dispose();
  }

  void _simpan() {
    if (!_kunci.currentState!.validate()) return;
    ScaffoldMessenger.of(context).showSnackBar(
      SnackBar(content: Text('Tersimpan: ${_judul.text.trim()}')),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Form Catatan')),
      body: Padding(
        padding: const EdgeInsets.all(16),
        child: Form(
          key: _kunci,
          child: Column(
            children: [
              TextFormField(
                controller: _judul,
                decoration: const InputDecoration(
                  labelText: 'Judul',
                  border: OutlineInputBorder(),
                ),
                validator: (v) => (v == null || v.trim().length < 3)
                    ? 'Judul minimal 3 karakter'
                    : null,
              ),
              const SizedBox(height: 16),
              FilledButton(onPressed: _simpan, child: const Text('Simpan')),
            ],
          ),
        ),
      ),
    );
  }
}
Hasil yang benar Judul kurang dari 3 karakter menampilkan pesan merah. Judul valid menampilkan SnackBar.

Praktik Modul 2 · Langkah 3 dari 3

Tata Letak Responsif

LANGKAH 3lib/main.dart (tambahkan kelas di bagian bawah)
  1. Tempel kelas ResponsivePage di akhir file.
  2. Ubah home menjadi const ResponsivePage().
  3. Putar emulator ke landscape atau ubah ukuran jendela.
class ResponsivePage extends StatelessWidget {
  const ResponsivePage({super.key});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Responsif')),
      body: LayoutBuilder(
        builder: (context, box) {
          final kolom = box.maxWidth >= 600 ? 3 : 1;
          return GridView.count(
            crossAxisCount: kolom,
            childAspectRatio: 3,
            padding: const EdgeInsets.all(16),
            crossAxisSpacing: 12,
            mainAxisSpacing: 12,
            children: List.generate(
              6,
              (i) => Card(child: Center(child: Text('Item ${i + 1}'))),
            ),
          );
        },
      ),
    );
  }
}
Hasil yang benar Layar sempit menampilkan 1 kolom. Layar lebar dari 600 dp menampilkan 3 kolom.
