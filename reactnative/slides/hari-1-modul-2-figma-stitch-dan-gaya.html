Sebelum menulis banyak kode, kita memutuskan seperti apa aplikasinya. Dua jam ini memakai alat desain modern: Google Stitch untuk rancangan awal dari prompt, dan Figma untuk merapikannya dengan Auto Layout dan variable. Variable itu menjadi token yang kita pindahkan ke kode, lalu kita minta AI menerapkan gaya baru ke aplikasi. Tekankan dua hal: AI mempercepat, tetapi manusia yang meninjau hasilnya, dan token membuat perubahan gaya cukup di satu tempat.

Konsep · simulasi: tekan S

Alur dari ide ke aplikasi

  • Mulai dari kebutuhan pengguna dan daftar layar, bukan dari warna.
  • **Google Stitch** membuat rancangan awal dari prompt, lalu diperbaiki lewat chat.
  • **Figma** merapikan rancangan: Auto Layout, komponen, dan **variable**. Berkas contoh pelatihan: https://www.figma.com/design/grYqOsULGfzYsDrtIjmjRL
  • Variable menjadi **token** di src/theme.ts. Komponen kode memakai token, bukan angka langsung.
  • AI membantu menerapkan gaya ke kode. Manusia meninjau hasilnya.
Gambarkan jalurnya di papan tulis: kebutuhan, prompt di Stitch, rapikan di Figma, variable menjadi token, token menjadi theme.ts, AI menerapkan, manusia meninjau. Buka simulasi untuk menelusuri enam langkahnya. Tanyakan mana langkah yang paling berisiko jika dilompati, jawabannya hampir selalu peninjauan manusia.

Konsep

Google Stitch

  • Alat dari Google Labs di stitch.withgoogle.com: teks atau gambar menjadi rancangan antarmuka dan kode front-end.
  • Perbaiki dengan chat, ubah tema, lalu salin atau ekspor ke Figma sebagai layer yang bisa diedit.
  • Hasil Stitch adalah **titik awal**. Rapikan struktur dan token sebelum menjadi kode aplikasi.
  • Fitur dan menu berubah cepat. Cek tampilan terbaru sebelum sesi dimulai.
Tunjukkan Stitch secara langsung bila ada akses. Tulis prompt yang menyebut layar, isi, dan gaya, lalu perbaiki lewat chat. Tekankan bahwa hasilnya titik awal. Fitur dan menu Stitch cepat berubah, jadi beri tahu peserta bahwa tampilan mereka mungkin sedikit berbeda.

Token menjadi theme.ts

Setiap variable Figma punya padanan di sini. Mengubah satu nilai mengubah seluruh aplikasi.

src/theme.ts

// Design token: satu sumber nilai gaya. Nilainya berasal dari variables di Figma.
export const tema = {
  warna: {
    utama: '#1565c0',
    latar: '#f5f7fb',
    kartu: '#ffffff',
    teks: '#1b1f27',
    abu: '#5f6b7a',
    garis: '#cfd6e0',
    bahaya: '#c62828',
    ok: '#2e7d32',
  },
  spasi: { xs: 4, sm: 8, md: 12, lg: 16, xl: 24 },
// ... selengkapnya di berkas ini
Buka simulasi token: geser warna, radius, spasi, dan font, lalu lihat kode dan tampilan berubah bersamaan. Itulah inti token. Tunjukkan bahwa nama di Figma dan di kode sengaja disamakan agar mudah dilacak.

Gaya dibuat dari tema. Target sentuh tombol 48 dp.

import { StyleSheet } from 'react-native';
import { tema } from './theme';

export const warna = tema.warna;

export const gaya = StyleSheet.create({
  layar: { flex: 1, backgroundColor: tema.warna.latar, padding: tema.spasi.lg },
  kartu: { backgroundColor: tema.warna.kartu, borderRadius: tema.radius.md, padding: 14, marginBottom: tema.spasi.md, elevation: 1 },
  judul: { fontSize: tema.font.judul, fontWeight: '700', color: tema.warna.teks },
  teks: { fontSize: tema.font.isi, color: tema.warna.teks, marginTop: tema.spasi.xs },
  abu: { fontSize: tema.font.kecil, color: tema.warna.abu, marginTop: tema.spasi.xs },
  input: { backgroundColor: tema.warna.kartu, borderWidth: 1, borderColor: tema.warna.garis, borderRadius: tema.radius.sm, padding: 10, marginBottom: 10, fontSize: tema.font.isi },
  tombol: { backgroundColor: tema.warna.utama, borderRadius: tema.radius.sm, minHeight: tema.tinggiTombol, justifyContent: 'center', alignItems: 'center', marginBottom: 10 },
// ... selengkapnya di berkas ini
Perhatikan bahwa ui.ts tidak punya angka mentah, semuanya membaca dari tema. Sebut juga tinggi tombol 48 dp sebagai target sentuh yang nyaman. Minta peserta mencari satu angka mentah yang masih tersisa di proyek mereka.

Konsep

Prompt AI untuk menerapkan gaya

  • Sertakan **konteks**: tumpukan teknologi (Expo, TypeScript), file src/theme.ts dan src/ui.ts.
  • Sertakan **tujuan**: gaya apa, layar mana, dan batasannya (jangan ubah logika).
  • Sertakan **bukti desain**: tangkapan layar Figma atau nilai variable.
  • Setelah AI mengubah kode: jalankan npm run typecheck dan npm test, lalu lihat hasilnya di perangkat.
  • Jangan menempelkan rahasia (token, kata sandi) ke alat AI.
Bahas empat bahan prompt yang baik: konteks, tujuan, bukti desain, dan batasan. Peringatkan agar tidak menempelkan rahasia ke alat AI. Tekankan bahwa hasil AI harus ditinjau sebagai diff, dijalankan typecheck dan tes, lalu dilihat di perangkat sebelum diterima.

Proyek Modul 2 · 60 menit

Redesain Dua Layar dengan Token

Ambil rancangan dua layar (Beranda dan Daftar) dari Stitch atau Figma, jadikan variable menjadi token, lalu implementasikan di aplikasi. Boleh meminta bantuan AI, tetapi hasilnya harus Anda tinjau.

  • Rancangan dua layar di Figma (boleh dimulai dari Stitch atau berkas contoh pelatihan).
  • Minimal 8 variable di Figma: warna, spasi, dan radius.
  • Berkas tema di kode dengan nama yang sama dengan variable Figma.
  • Dua layar di aplikasi memakai tema, tanpa angka warna atau jarak mentah di komponen.
  • Tangkapan layar perbandingan: desain di samping hasil aplikasi.
  • Catatan singkat prompt AI yang dipakai dan satu hal yang Anda koreksi dari hasil AI.

Brief lengkap: shared/docs/proyek/modul-2-redesain-dua-layar-dengan-token.md

Proyek ini adalah irisan kecil yang bisa berdiri sendiri dan nanti dapat digabung ke proyek akhir. Bacakan skenario, lalu minta peserta memilih satu syarat yang paling menantang bagi mereka. Kriteria penerimaan dan rubrik ada di brief lengkap.
