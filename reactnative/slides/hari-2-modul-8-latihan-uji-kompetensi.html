Latihan dan Persiapan Uji Kompetensi

Elemen yang dinilai:

  1. Seluruh elemen tujuh unit kompetensi

Bukti pada pelatihan ini: aplikasi berjalan, npm test lulus, npm run typecheck bersih, hasil latihan soal

Slide ini menghubungkan materi dengan sertifikasi. Setiap modul sesuai satu unit kompetensi, dan setiap unit punya elemen yang dinilai. Baca elemennya satu per satu, lalu tunjukkan di bagian bukti file mana yang akan menjadi bahan tunjukan saat asesmen.

Konsep

Daftar periksa aplikasi

  • Desain: token di src/theme.ts sama dengan variable Figma.
  • Catatan: tambah, ubah, hapus, data tetap ada setelah aplikasi ditutup.
  • Lokasi: izin diminta saat tombol ditekan, koordinat tersimpan di SQLite.
  • API: login, sinkronisasi, dan penanganan server mati berjalan.
  • Sensor: angka tampil, guncangan terdeteksi, langganan dihentikan.
  • Keamanan: HTTP publik ditolak, token tersimpan aman.
Gunakan daftar ini seperti pengguna baru: buka setiap menu, coba jalur normal, lalu coba jalur gagal seperti menolak izin dan mematikan internet. Peserta mencentang satu per satu. Yang gagal dicatat dan diperbaiki sebelum lanjut.

Konsep

Menyiapkan bukti BNSP

  • Siapkan aplikasi yang berjalan di perangkat atau emulator.
  • Tunjukkan file kode yang menjadi bukti tiap unit (lihat peta kompetensi).
  • Jalankan npm test dan npm run typecheck sebagai bukti kualitas.
  • Latih penjelasan lisan: apa yang dibuat, mengapa, dan bagaimana mengujinya.
Asesor ingin melihat dua hal: aplikasi berjalan, dan peserta paham yang dibuatnya. Siapkan satu file bukti untuk setiap unit dan latih penjelasan dua menit: apa yang dibuat, mengapa dipilih, dan bagaimana mengujinya. Jalankan npm test sebagai bukti kualitas.

Proyek Modul 8 · 60 menit

Paket Bukti Kompetensi

Siapkan bukti untuk uji kompetensi: aplikasi berjalan, kode yang menjadi bukti tiap unit, tes hijau, dan penjelasan lisan lima menit.

  • Tabel bukti: satu baris per unit kompetensi (tujuh unit) berisi berkas kode atau layar yang membuktikannya.
  • Semua tes lulus dan pemeriksaan tipe atau analisis bersih (npm test, npm run typecheck atau flutter analyze, flutter test).
  • README proyek: cara menjalankan, fitur, dan tangkapan layar.
  • Skrip demo lima menit: apa yang dibuat, mengapa, bagaimana menguji.

Brief lengkap: shared/docs/proyek/modul-8-paket-bukti-kompetensi.md

Proyek ini adalah irisan kecil yang bisa berdiri sendiri dan nanti dapat digabung ke proyek akhir. Bacakan skenario, lalu minta peserta memilih satu syarat yang paling menantang bagi mereka. Kriteria penerimaan dan rubrik ada di brief lengkap.
