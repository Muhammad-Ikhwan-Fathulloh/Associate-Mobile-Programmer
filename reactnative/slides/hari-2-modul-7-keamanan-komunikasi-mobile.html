Penyimpanan aman

Token disimpan di Keystore Android atau Keychain iOS.

src/services/secureStorage.ts

import * as SecureStore from 'expo-secure-store';

const KUNCI = 'token_demo';

export const simpanToken = (nilai: string) => SecureStore.setItemAsync(KUNCI, nilai);
export const bacaToken = () => SecureStore.getItemAsync(KUNCI);
export const hapusToken = () => SecureStore.deleteItemAsync(KUNCI);
Token dan kata sandi tidak boleh disimpan sebagai teks biasa. Secure store memakai Keystore di Android dan Keychain di iOS, yang dilindungi perangkat keras. Buka simulasinya: simpan, baca, hapus. Tekankan bahwa tempat ini untuk rahasia kecil, bukan untuk data besar.

Konsep · simulasi: tekan S

Prinsip pengamanan aplikasi

  • Selalu **HTTPS**. Jangan menonaktifkan pemeriksaan sertifikat.
  • Rahasia di **secure store**, bukan di SQLite atau teks biasa.
  • **Validasi masukan** di aplikasi dan di server.
  • Jangan menaruh API key rahasia di dalam kode aplikasi.
  • Minta **izin seperlunya** dan jelaskan alasannya.
Rangkum dengan lima prinsip yang bisa dicek di kode: selalu HTTPS, rahasia di secure store, validasi masukan, jangan taruh kunci rahasia di dalam aplikasi, dan minta izin seperlunya. Buka simulasi autentikasi: login untuk mendapat token, lalu coba endpoint dengan dan tanpa token. Diskusikan mengapa token itu harus disimpan di secure store.
