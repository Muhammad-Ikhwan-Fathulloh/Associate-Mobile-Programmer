Mulai dengan bertanya: siapa yang pakai Android, siapa iOS? Jawaban peserta membuka diskusi. Tunjukkan bahwa perbedaan terpenting bagi pengembang ada di tiga hal: bahasa, alat, dan cara distribusi. Satu catatan praktis: Xcode hanya ada di macOS, sehingga membangun aplikasi iOS membutuhkan Mac. Itu salah satu alasan banyak tim memilih kerangka kerja lintas platform.

Cara kerja React Native

  • Kode ditulis dengan **komponen React** dan bahasa **TypeScript**.
  • JavaScript berjalan di mesin JS dalam aplikasi, lalu memerintahkan pembuatan **view native** (Text menjadi teks Android/iOS asli).
  • **Expo** menyediakan alat build dan modul siap pakai (SQLite, lokasi, sensor).
  • **Expo Go** memungkinkan menjalankan proyek di ponsel dengan memindai kode QR.
Poin utama: React Native tidak menampilkan halaman web. Kode JavaScript berjalan di dalam aplikasi dan memerintahkan pembuatan tampilan asli. Itu sebabnya hasilnya terasa seperti aplikasi biasa. Buka simulasi di slide ini, pilih komponen, lalu ganti platform untuk melihat padanannya di Android dan iOS. Expo adalah lapisan yang membuat proses build dan uji jauh lebih mudah.

Contoh Kode

TypeScript dasar

type Mahasiswa = { nama: string; nilai: number };

const daftar: Mahasiswa[] = [
  { nama: 'Ani', nilai: 90 },
  { nama: 'Budi', nilai: 72 },
];

const lulus = daftar.filter((m) => m.nilai >= 75);
console.log(lulus.map((m) => m.nama)); // ['Ani']

async function ambil(url: string): Promise<unknown> {
  const res = await fetch(url);
  return res.json();
}
TypeScript adalah JavaScript dengan tipe. Tunjukkan bahwa menulis tipe Mahasiswa membuat editor langsung memberi tahu bila kita salah mengetik nama properti. Jelaskan tiga hal yang akan sering muncul: type, filter dan map pada array, serta async await untuk pekerjaan yang butuh waktu seperti memanggil server. Peserta tidak perlu hafal, cukup mengenali bentuknya.
