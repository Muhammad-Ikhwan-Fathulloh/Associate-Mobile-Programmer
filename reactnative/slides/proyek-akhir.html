Proyek Akhir

Proyek Akhir: Aplikasi Buatan Anda

by Muhammad Ikhwan Fathulloh

Bangun satu aplikasi utuh yang menggabungkan seluruh materi: desain, SQLite, GPS, API, sensor, dan keamanan. Mulailah dari proyek dasar (capstone-base) lalu ubah menjadi aplikasi dengan tema pilihan Anda.

Dokumen: shared/docs/proyek/capstone.md

Pilih tema

Enam Ide Tema

TemaGambaran
Jurnal PerjalananCatatan perjalanan dengan foto lokasi, peta jejak, dan kategori. Sensor: kompas arah tujuan.
Pelacak Kebiasaan BerlokasiKebiasaan yang dicatat di tempat tertentu (gym, perpustakaan). Sensor: guncang untuk catat cepat.
Laporan WargaLaporan masalah (jalan rusak, lampu mati) dengan lokasi dan kategori, dikirim ke server. Sensor: guncang untuk laporan darurat.
Daftar Belanja Dekat TokoDaftar belanja yang mengingatkan saat dekat toko favorit. Sensor: kompas menuju toko.
Pelacak OlahragaCatat sesi lari atau jalan, jarak dari titik GPS, dan hitung langkah kasar dari akselerometer.
Katalog UMKM SekitarDaftar usaha kecil di sekitar dengan jarak dan peta. Data dari server latihan.

Proyek dasar

Mulai dari Capstone Base

  • React Native: reactnative/capstone-base. Flutter: flutter/capstone-base.
  • Sudah ada: struktur berlapis, tema, SQLite, GPS, klien API, sinkronisasi, sensor, dan tes.
  • Ubah proyek.config untuk nama aplikasi, nama entri, dan warna.
  • Kerjakan slot bertanda TODO(peserta) lalu tambahkan fitur kreatif.

Dokumen: shared/docs/proyek/capstone.md

Syarat

Matriks Fitur Wajib

ModulTopikYang harus ada
1Platform dan bahasaAplikasi berjalan di emulator atau perangkat, kode bertipe, komponen dipakai ulang.
2DesainRancangan di Figma atau Stitch (minimal 3 layar), variable menjadi token di berkas tema, tanpa angka mentah.
3SQLiteMinimal satu tabel dengan CRUD lengkap, repository terpisah, data bertahan, satu migrasi.
4GPSKoordinat tersimpan di SQLite, izin dan kegagalan ditangani, jarak atau peta ditampilkan.
5 dan 7API dan sinkronisasiLogin, kirim dan ambil data, status PENDING dan SYNCED, token di penyimpanan aman, HTTP publik ditolak.
6SensorMinimal satu sensor dipakai dengan makna (bukan sekadar menampilkan angka), langganan dihentikan.
8KualitasMinimal 8 tes lulus, analisis bersih, README, dan demo lima menit.
