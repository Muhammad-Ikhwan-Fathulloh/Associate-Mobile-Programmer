Konsep

Rantai sensor

  • Sensor mengukur besaran fisik, lalu diubah menjadi sinyal listrik.
  • Konverter analog ke digital (ADC) menghasilkan angka.
  • Prosesor dan sistem operasi menyediakan angka itu bagi aplikasi.
  • Protokol antarmuka umum ke chip sensor: **I2C** dan **SPI**.
Sensor mengukur besaran fisik, lalu diubah menjadi sinyal listrik, didigitalkan oleh ADC, diproses prosesor, dan akhirnya sampai ke aplikasi. Protokol I2C dan SPI adalah jalur chip sensor berbicara dengan prosesor. Cukup kenali namanya dan perannya.

Konsep · simulasi: tekan S

Giroskop dan kompas

  • **Giroskop** mengukur laju putar (rad/s). Sudut didapat dengan mengakumulasi laju terhadap waktu, hasilnya cenderung bergeser (drift).
  • **Magnetometer** mengukur medan magnet bumi. Arah kompas dihitung dari komponen x dan y.
  • Padukan sensor (sensor fusion) untuk arah yang stabil. Di pelatihan ini pendekatan sederhana dipakai dan diberi catatan akurasinya.
Buka simulasi giroskop dan geser sumbu z. Perhatikan bahwa giroskop memberi kecepatan putar, bukan sudut. Sudut didapat dengan menjumlahkan kecepatan terhadap waktu, dan hasilnya perlahan bergeser. Itu sebabnya kompas membutuhkan magnetometer.

Membaca akselerometer

Berlangganan dengan addListener, berhenti dengan remove.

app/sensor.tsx

  useEffect(() => {
    let langganan: { remove: () => void } | undefined;
    sensor.isAvailableAsync().then((ok) => {
      setTersedia(ok);
      if (!ok) return;
      sensor.setUpdateInterval(intervalMs);
      langganan = sensor.addListener(setNilai);
    });
    return () => langganan?.remove();
  }, [sensor, intervalMs]);

  return { nilai, tersedia };
}

Perhatikan jumlah pendengar menumpuk. Itulah kebocoran yang menguras baterai, dan itu sebabnya cleanup wajib ditulis.

Menghitung guncangan dan arah

Fungsi murni, mudah diuji: besar vektor, deteksi guncangan, arah kompas, dan mata angin.

src/services/sensorMath.ts

export function terdeteksiGuncangan(v: Vektor, ambang = 2): boolean {
  return besarVektor(v) > ambang;
}

/**
 * Perkiraan arah kompas (derajat, 0 = utara, searah jarum jam) dari magnetometer
 * saat ponsel datar. Hasilnya perkiraan: sumbu sensor dapat berbeda antarperangkat.
 */
export function arahKompas(m: Pick<Vektor, 'x' | 'y'>): number {
  const derajat = (Math.atan2(-m.x, m.y) * 180) / Math.PI;
  return (derajat + 360) % 360;
}

// ... selengkapnya di berkas ini
Fungsi di berkas ini murni, jadi mudah diuji tanpa perangkat. Tunjukkan ambang 2 g untuk guncangan dan jelaskan bahwa arah kompas adalah pendekatan sederhana yang dipengaruhi benda logam di sekitar ponsel.

Konsep

Praktik baik penggunaan sensor

  • Periksa ketersediaan sensor sebelum memakai.
  • Pilih interval pembaruan secukupnya agar baterai hemat.
  • Hentikan langganan saat halaman ditutup.
  • Kumpulkan data perangkat seperlunya demi privasi.
Empat kebiasaan: periksa dulu apakah sensor ada, pilih interval secukupnya, hentikan langganan saat halaman ditutup, dan kumpulkan data seperlunya. Minta peserta memilih satu yang paling sering dilupakan, lalu jelaskan dampaknya pada baterai.

Penghitung Guncangan dan Kompas

Buat alat kecil yang membaca sensor: menghitung berapa kali ponsel diguncang, menampilkan arah kompas, dan menampilkan kecepatan putar. Fokus pada fungsi perhitungan yang bisa diuji.

  • Akselerometer: deteksi guncangan bila besar vektor melewati ambang, dengan jeda agar satu guncangan tidak dihitung berkali-kali.
  • Magnetometer: arah dalam derajat dan mata angin (U, TL, T, TG, S, BD, B, BL).
  • Giroskop: tampilkan kecepatan putar tiga sumbu.
  • Berhenti membaca sensor saat halaman ditutup.
  • Fungsi perhitungan murni dan diuji tanpa perangkat.

Brief lengkap: shared/docs/proyek/modul-6-penghitung-guncangan-dan-kompas.md

Proyek ini adalah irisan kecil yang bisa berdiri sendiri dan nanti dapat digabung ke proyek akhir. Bacakan skenario, lalu minta peserta memilih satu syarat yang paling menantang bagi mereka. Kriteria penerimaan dan rubrik ada di brief lengkap.
