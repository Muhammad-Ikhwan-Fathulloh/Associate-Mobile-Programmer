Modul 8: Latihan Uji Kompetensi dan Pembahasan

Tujuan Pembelajaran

  1. Mengerjakan latihan soal teori dan praktik.
  2. Membahas jawaban dan kesalahan yang sering terjadi.
  3. Menyusun rencana belajar mandiri sebelum uji kompetensi.

Tata cara membuat

  1. Kerjakan teori tanpa membuka materi.
  2. Lanjut praktik di proyek app/.
  3. Ikuti pembahasan dan catat kesalahan.
  4. Susun rencana belajar mandiri.

Tugas 2: Unit Test Tambahan

Praktik Modul 8 · Langkah 3 dari 3

Tugas 3: Konfirmasi Hapus Token

LANGKAH 3lib/pages/keamanan_page.dart
  1. Ganti method _hapus dengan kode di bawah.
  2. Jalankan halaman keamanan.
  3. Tekan Hapus: dialog konfirmasi harus muncul.
  Future<void> _hapus() async {
    final yakin = await showDialog<bool>(
      context: context,
      builder: (context) => AlertDialog(
        title: const Text('Hapus token?'),
        content: const Text('Token akan dihapus dari secure storage.'),
        actions: [
          TextButton(
            onPressed: () => Navigator.pop(context, false),
            child: const Text('Batal'),
          ),
          FilledButton(
            onPressed: () => Navigator.pop(context, true),
            child: const Text('Hapus'),
          ),
        ],
      ),
    );
    if (yakin != true || !mounted) return;
    await _storage.hapusToken();
    await _muatToken();
    _pesan('Token dihapus.');
  }
Hasil yang benar Dialog muncul. Batal tidak menghapus, Hapus menghapus token dan menampilkan pesan.
