Modul 2: Perancangan Mobile Interface

Tujuan Pembelajaran

  1. Menerapkan prinsip UI dan UX pada aplikasi mobile.
  2. Menggunakan widget dasar dan layout Flutter.
  3. Membuat tema konsisten dengan Material 3.
  4. Membuat layout responsif dan navigasi antarlayar.

Materi: docs/hari-1/02-mobile-interface.md

Prinsip

Prinsip UI dan UX Mobile

  • Keterbacaan: teks isi minimal 14, kontras minimal 4.5:1 untuk teks normal.
  • Area sentuh: minimal 48 x 48 logical pixel.
  • Thumb zone: aksi utama di area yang mudah dijangkau ibu jari.
  • Hierarki visual: ukuran, warna, dan spasi menunjukkan prioritas.
  • Konsistensi: pola navigasi dan komponen seragam.
  • Umpan balik: setiap aksi memberi respons visual yang jelas.

Navigasi

Navigasi dengan go_router

final appRouter = GoRouter(
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomePage(),
    ),
    GoRoute(
      path: '/detail/:id',
      builder: (context, state) => Text(
        'Detail: ${state.pathParameters['id']}',
      ),
    ),
  ],
);

// Membuka layar baru dan menyimpannya di tumpukan
context.push('/detail/42');
// Kembali ke layar sebelumnya
context.pop();
