  4. Catat dampak ke aplikasi: ukuran data dan waktu tunggu.

Materi: Bagian 1. Perkembangan Generasi Seluler

Arsitektur

Arsitektur Dasar

  • User Equipment (UE): perangkat dengan SIM atau eSIM.
  • Radio Access Network (RAN): menara yang melayani perangkat melalui gelombang radio.
  • Core Network: mengatur autentikasi, sesi data, dan tagihan.
Aplikasi -> Sistem operasi -> Modem -> Menara (RAN) -> Core Network -> Internet

Tata cara membuat

  1. Gambar UE di bawah, menara di tengah.
  2. Tambahkan Core Network sebagai pusat kendali.
  3. Sambungkan ke internet.
  4. Beri label jalur data dan jalur sinyal.

Materi: Bagian 2. Arsitektur Dasar

Konsep

Spektrum, Handover, dan Roaming

Spektrum

Frekuensi rendah menjangkau luas, frekuensi tinggi berkapasitas besar tetapi jangkauannya pendek.

Handover

Perpindahan koneksi antar-menara tanpa memutus sesi.

Roaming

Penggunaan jaringan operator lain di luar area layanan utama.

Tata cara membuat

  1. Gambar dua area sel yang saling beririsan.
  2. Tandai jalur perpindahan perangkat.
  3. Tandai titik handover di area irisan.
  4. Bandingkan dengan roaming: pindah ke jaringan operator lain.

Praktik Modul 5 · Langkah 2 dari 3

Cek Koneksi Sekali

LANGKAH 2lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan aplikasi.
  3. Tekan tombol Periksa.
import 'package:connectivity_plus/connectivity_plus.dart';
import 'package:flutter/material.dart';

String label(List<ConnectivityResult> hasil) {
  if (hasil.isEmpty || hasil.contains(ConnectivityResult.none)) {
    return 'Tidak ada koneksi';
  }
  if (hasil.contains(ConnectivityResult.wifi)) return 'Wi-Fi';
  if (hasil.contains(ConnectivityResult.mobile)) return 'Seluler';
  return 'Lainnya';
}

void main() => runApp(const MaterialApp(home: JaringanPage()));

class JaringanPage extends StatefulWidget {
  const JaringanPage({super.key});

  @override
  State<JaringanPage> createState() => _JaringanPageState();
}

class _JaringanPageState extends State<JaringanPage> {
  String _teks = 'Tekan Periksa';

  Future<void> _periksa() async {
    final hasil = await Connectivity().checkConnectivity();
    setState(() => _teks = label(hasil));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Jaringan')),
      body: Center(
        child: Text(_teks, style: Theme.of(context).textTheme.headlineMedium),
      ),
      floatingActionButton: FloatingActionButton.extended(
        onPressed: _periksa,
        label: const Text('Periksa'),
      ),
    );
  }
}
Hasil yang benar Teks menampilkan Wi-Fi, Seluler, atau Tidak ada koneksi sesuai kondisi saat ditekan.

Praktik Modul 5 · Langkah 3 dari 3

Pantau Perubahan (Stream)

LANGKAH 3lib/main.dart (ganti kelas _JaringanPageState)
  1. Tambahkan import 'dart:async'; di baris paling atas.
  2. Ganti _JaringanPageState dengan kode di bawah.
  3. Matikan lalu nyalakan Wi-Fi atau mode pesawat, amati teks.
class _JaringanPageState extends State<JaringanPage> {
  List<ConnectivityResult> _hasil = [];
  StreamSubscription<List<ConnectivityResult>>? _langganan;

  @override
  void initState() {
    super.initState();
    Connectivity().checkConnectivity().then((h) {
      if (mounted) setState(() => _hasil = h);
    });
    _langganan = Connectivity().onConnectivityChanged.listen((h) {
      setState(() => _hasil = h);
    });
  }

  @override
  void dispose() {
    _langganan?.cancel();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Jaringan')),
      body: Center(
        child: Text(
          label(_hasil),
          style: Theme.of(context).textTheme.headlineMedium,
        ),
      ),
    );
  }
}
Hasil yang benar Teks berubah sendiri tanpa tombol. dispose membatalkan langganan agar tidak bocor.
