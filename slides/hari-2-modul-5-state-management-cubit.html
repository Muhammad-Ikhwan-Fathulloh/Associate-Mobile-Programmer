Modul 5: State Management dengan Cubit

Tujuan Pembelajaran

  1. Menjelaskan perbedaan setState dan state management terpusat.
  2. Membuat Cubit dan state yang immutable.
  3. Menghubungkan Cubit ke UI dengan BlocProvider, BlocBuilder, dan BlocListener.

Materi: docs/hari-2/05-state-management-cubit.md

Konsep

Mengapa State Management

  • setState cukup untuk state lokal di satu widget.
  • Ketika state dipakai banyak layar, logika bisnis perlu dipisahkan dari UI.
  • Cubit memindahkan logika ke method di dalam kelas, sedangkan widget hanya menampilkan state.

Model

Model dengan Equatable

class Todo extends Equatable {
  final String id;
  final String judul;
  final bool selesai;

  const Todo({required this.id, required this.judul, this.selesai = false});

  Todo copyWith({String? judul, bool? selesai}) {
    return Todo(
      id: id,
      judul: judul ?? this.judul,
      selesai: selesai ?? this.selesai,
    );
  }

  @override
  List<Object?> get props => [id, judul, selesai];
}

Cubit

Cubit

class TodoCubit extends Cubit<TodoState> {
  TodoCubit() : super(const TodoState());

  void tambah(String judul) {
    final todo = Todo(
      id: DateTime.now().microsecondsSinceEpoch.toString(),
      judul: judul,
    );
    emit(TodoState(daftar: [...state.daftar, todo]));
  }

  void ubahStatus(String id) {
    emit(TodoState(
      daftar: state.daftar
          .map((t) => t.id == id ? t.copyWith(selesai: !t.selesai) : t)
          .toList(),
    ));
  }
}
  • State tidak boleh diubah langsung. Setiap perubahan membuat list baru lalu dikirim lewat emit.

Materi: Bagian 4. Cubit

UI

Menghubungkan Cubit ke UI

BlocProvider(
  create: (_) => TodoCubit(),
  child: const TodoPage(),
);

BlocBuilder<TodoCubit, TodoState>(
  builder: (context, state) {
    return ListView.builder(
      itemCount: state.daftar.length,
      itemBuilder: (context, index) {
        final todo = state.daftar[index];
        return ListTile(
          title: Text(todo.judul),
          onTap: () => context.read<TodoCubit>().ubahStatus(todo.id),
        );
      },
    );
  },
);
