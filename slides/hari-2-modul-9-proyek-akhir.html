Modul 9: Proyek Akhir

Tujuan

Peserta membangun satu aplikasi utuh yang mengintegrasikan materi Hari 1 dan Hari 2, lalu mempresentasikannya.

  • Dikerjakan secara individu atau berpasangan.
  • Menggunakan Flutter dan Dart.
  • Kode dikelola dengan Git dan diunggah ke repositori GitHub masing-masing.
  • Wajib memiliki minimal satu unit test dan satu widget test.

Tahapan

Tahapan Pengerjaan

  1. Rancang fitur dan gambarkan alur layar.
  2. Buat struktur proyek dan konfigurasi dependensi.
  3. Implementasikan data lokal atau API.
  4. Implementasikan state dengan Cubit dan UI.
  5. Tambahkan izin, penanganan error, dan validasi.
  6. Tulis pengujian.
  7. Siapkan presentasi 5 menit dengan demo langsung.

Materi: Tahapan

Presentasi

Format Presentasi dan Checklist

Format (5 menit)

  • Demo aplikasi: 2 menit.
  • Arsitektur dan keputusan teknis: 2 menit.
  • Tanya jawab: 1 menit.

Checklist pengumpulan

  • flutter run berjalan tanpa error.
  • flutter analyze tanpa error.
  • flutter test lulus.
  • README berisi nama, cara menjalankan, dan daftar fitur.
  • Kode diunggah ke GitHub.
