Unit test

Unit Test Fungsi

import 'package:flutter_test/flutter_test.dart';
import 'package:associate_mobile_app/services/distance.dart';

void main() {
  test('jarak titik yang sama bernilai nol', () {
    expect(jarakMeter(-6.2, 106.8, -6.2, 106.8), closeTo(0, 0.001));
  });

  test('jarak Jakarta ke Bandung sekitar 120 km', () {
    final jarak = jarakMeter(-6.2088, 106.8456, -6.9175, 107.6191);
    expect(jarak / 1000, closeTo(120, 10));
  });
}

Rilis

Build Rilis Android

flutter build apk --release         # untuk distribusi langsung
flutter build appbundle --release  # untuk Google Play Store
  • Hasil APK berada di build/app/outputs/.
  • Format versi di pubspec.yaml: version: 1.0.0+1 (versi-nama+build-number).
  • Build release memakai signing debug secara default. Untuk publikasi, buat keystore sendiri.

Materi: Bagian 5. Build Rilis Android · Panduan resmi: docs.flutter.dev/deployment/android

Publikasi

Publikasi ke Google Play Store

  1. Buat akun Google Play Console dan bayar biaya pendaftaran satu kali.
  2. Buat aplikasi baru dan lengkapi data toko: deskripsi, ikon, tangkapan layar, dan kebijakan privasi.
  3. Unggah file .aab ke jalur rilis internal testing.
  4. Isi formulir konten, rating, dan keamanan data.
  5. Kirim untuk ditinjau.
