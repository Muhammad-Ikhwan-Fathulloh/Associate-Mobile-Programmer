Perancangan

Perancangan Tabel

  1. Identifikasi entitas, misalnya notes.
  2. Tentukan atribut dan tipenya.
  3. Tentukan primary key dan kolom wajib.
  4. Tentukan relasi melalui foreign key.
  5. Tambahkan indeks pada kolom yang sering dikueri.
notes
├── id          INTEGER  PRIMARY KEY AUTOINCREMENT
├── title       TEXT     NOT NULL
├── content     TEXT     NOT NULL
├── latitude    REAL
├── longitude   REAL
├── updated_at  INTEGER  NOT NULL
└── sync_status TEXT     NOT NULL DEFAULT 'PENDING'

Tata cara membuat

  1. Tulis kebutuhan data: apa yang disimpan dan wajib atau tidak.
  2. Tentukan kunci utama id dengan AUTOINCREMENT.
  3. Pilih tipe: TEXT, INTEGER, REAL.
  4. Tambahkan indeks pada kolom yang sering diurutkan, misalnya updated_at.

  4. Aktifkan PRAGMA foreign_keys = ON di onConfigure.

CRUD

Repository (CRUD)

Future<List<Note>> ambilSemua() async {
  final db = await AppDatabase.instance;
  final rows = await db.query('notes', orderBy: 'updated_at DESC');
  return rows.map(Note.fromMap).toList();
}

Future<int> simpan(Note note) async {
  final db = await AppDatabase.instance;
  final values = note.toMap()..remove('id');
  return db.insert('notes', values);
}

Future<int> hapus(int id) async {
  final db = await AppDatabase.instance;
  return db.delete('notes', where: 'id = ?', whereArgs: [id]);
}
  • whereArgs mencegah SQL injection. Jangan menggabungkan input pengguna ke string SQL.

Tata cara membuat

  1. Buat class NoteRepository dengan method ambilSemua, simpan, ubah, hapus.
  2. Pakai whereArgs agar query aman dari injeksi SQL.
  3. Repository hanya mengurus data, tidak tahu soal UI.
  4. Controller memanggil repository dan memberi tahu UI.

Konsep

Offline-First dan Sinkronisasi

  • Data ditulis ke database lokal terlebih dahulu, lalu disinkronkan ke server di latar belakang.
  • Kolom sync_status menandai data: PENDING, SYNCED, atau FAILED.
  • Antrean unggahan dijalankan saat koneksi tersedia.
  • Resolusi konflik, misalnya last-write-wins berdasarkan updated_at.

Tata cara membuat

  1. Selalu simpan ke SQLite lebih dulu.
  2. Beri sync_status = PENDING pada data baru.
  3. Saat jaringan tersedia, kirim data PENDING ke server.
  4. Setelah berhasil, ubah status menjadi SYNCED.

Lapisan Database

LANGKAH 1lib/db.dart
  1. Buat file baru lib/db.dart.
  2. Tempel kode, simpan.
  3. Perhatikan onCreate hanya berjalan saat database pertama dibuat.
import 'package:path/path.dart';
import 'package:sqflite/sqflite.dart';

class Db {
  static Database? _db;

  static Future<Database> get instance async {
    if (_db != null) return _db!;
    final lokasi = join(await getDatabasesPath(), 'latihan.db');
    _db = await openDatabase(
      lokasi,
      version: 1,
      onCreate: (db, versi) => db.execute(
        'CREATE TABLE catatan ('
        'id INTEGER PRIMARY KEY AUTOINCREMENT, '
        'judul TEXT NOT NULL)',
      ),
    );
    return _db!;
  }

  static Future<List<Map<String, Object?>>> semua() async {
    final db = await instance;
    return db.query('catatan', orderBy: 'id DESC');
  }

  static Future<int> tambah(String judul) async {
    final db = await instance;
    return db.insert('catatan', {'judul': judul});
  }

  static Future<int> hapus(int id) async {
    final db = await instance;
    return db.delete('catatan', where: 'id = ?', whereArgs: [id]);
  }
}

Tampilan Catatan

LANGKAH 2lib/main.dart
  1. Ganti seluruh isi lib/main.dart.
  2. Jalankan di emulator atau ponsel (bukan web).
  3. Tambahkan beberapa catatan lewat kolom teks.
import 'package:flutter/material.dart';

import 'db.dart';

void main() => runApp(const MaterialApp(home: CatatanPage()));

class CatatanPage extends StatefulWidget {
  const CatatanPage({super.key});

  @override
  State<CatatanPage> createState() => _CatatanPageState();
}

class _CatatanPageState extends State<CatatanPage> {
  final _input = TextEditingController();
  List<Map<String, Object?>> _data = [];

  @override
  void initState() {
    super.initState();
    _muat();
  }

  @override
  void dispose() {
    _input.dispose();
    super.dispose();
  }

  Future<void> _muat() async {
    final hasil = await Db.semua();
    if (!mounted) return;
    setState(() => _data = hasil);
  }

  Future<void> _tambah() async {
    final teks = _input.text.trim();
    if (teks.isEmpty) return;
    await Db.tambah(teks);
    _input.clear();
    await _muat();
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Catatan SQLite')),
      body: Column(
        children: [
          Padding(
            padding: const EdgeInsets.all(12),
            child: Row(
              children: [
                Expanded(
                  child: TextField(
                    controller: _input,
                    decoration: const InputDecoration(hintText: 'Tulis catatan'),
                  ),
                ),
                IconButton(onPressed: _tambah, icon: const Icon(Icons.add)),
              ],
            ),
          ),
          Expanded(
            child: ListView.builder(
              itemCount: _data.length,
              itemBuilder: (context, i) {
                final baris = _data[i];
                return ListTile(
                  title: Text('${baris['judul']}'),
                  trailing: IconButton(
                    icon: const Icon(Icons.delete),
                    onPressed: () async {
                      await Db.hapus(baris['id'] as int);
                      await _muat();
                    },
                  ),
                );
              },
            ),
          ),
        ],
      ),
    );
  }
}
