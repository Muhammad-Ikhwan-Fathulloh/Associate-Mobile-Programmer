Custom widget

Custom Widget

class KartuTugas extends StatelessWidget {
  final String judul;
  final bool selesai;
  final VoidCallback onTap;

  const KartuTugas({
    super.key,
    required this.judul,
    required this.selesai,
    required this.onTap,
  });

  @override
  Widget build(BuildContext context) {
    final tema = Theme.of(context);
    return Card(
      child: InkWell(
        onTap: onTap,
        child: Padding(
          padding: const EdgeInsets.all(16),
          child: Text(
            judul,
            style: tema.textTheme.titleMedium?.copyWith(
              decoration: selesai ? TextDecoration.lineThrough : null,
            ),
          ),
        ),
      ),
    );
  }
}

Animasi

Implicit Animation

Animasi berjalan otomatis saat nilai properti berubah melalui setState.

AnimatedContainer(
  duration: const Duration(milliseconds: 400),
  curve: Curves.easeInOut,
  width: _besar ? 220 : 120,
  height: _besar ? 220 : 120,
  decoration: BoxDecoration(
    color: _besar ? Colors.indigo : Colors.teal,
    borderRadius: BorderRadius.circular(_besar ? 32 : 8),
  ),
);

Hero

Hero Animation

Widget yang sama dianimasikan saat berpindah layar. Kedua layar memakai tag yang sama.

// Layar daftar
Hero(
  tag: 'post-${post.id}',
  child: Text(post.judul),
);

// Layar detail, tag sama
Hero(
  tag: 'post-${post.id}',
  child: Text(post.judul),
);
