# Proyek Modul 8: Paket Bukti Kompetensi

Modul 8: Latihan dan Persiapan Uji Kompetensi · Estimasi 60 menit · Unit BNSP Semua unit

by [Muhammad Ikhwan Fathulloh](https://one.nocturnailed.com/)

## Skenario

Siapkan bukti untuk uji kompetensi: aplikasi berjalan, kode yang menjadi bukti tiap unit, tes hijau, dan penjelasan lisan lima menit.

## Yang harus dibuat

- [ ] Tabel bukti: satu baris per unit kompetensi (tujuh unit) berisi berkas kode atau layar yang membuktikannya.
- [ ] Semua tes lulus dan pemeriksaan tipe atau analisis bersih (`npm test`, `npm run typecheck` atau `flutter analyze`, `flutter test`).
- [ ] README proyek: cara menjalankan, fitur, dan tangkapan layar.
- [ ] Skrip demo lima menit: apa yang dibuat, mengapa, bagaimana menguji.

## Kriteria penerimaan

Proyek dianggap selesai bila semua ini dapat didemonstrasikan:

- Setiap baris tabel bukti menunjuk berkas yang benar-benar ada.
- Orang lain dapat menjalankan aplikasi hanya dengan mengikuti README.
- Demo selesai dalam 5 menit dan memperlihatkan satu kasus gagal yang ditangani.

## Petunjuk React Native

- Gunakan peta bukti di `reactnative/docs/sertifikasi-bnsp.md` sebagai contoh.

## Petunjuk Flutter

- Gunakan peta bukti di `flutter/docs/sertifikasi-bnsp/`.

## Tantangan tambahan

- Latih demo di depan teman dan minta mereka mencari satu bug.
