Rangkuman Aplikasi

Folder app/ berisi proyek Flutter lengkap yang dibangun dari panduan hands-on. Proyek ini dipakai sebagai contoh jadi untuk setiap modul.

  • Kode aplikasi (app/)
  • Dependensi (pubspec.yaml)
  • Router (app_router.dart)
  • Unit dan widget test (app/test/)
